# Daily Practice Log

Use this log to record real work completed in an existing project or study repo. Keep each entry short and specific; do not add an entry for a day when no work was done.

## Daily entry template

Copy this block into a dated file such as `YYYY-MM-DD.md`:

```md
# YYYY-MM-DD

- **Repo:** 
- **Worked on:** 
- **What changed or what I learned:** 
- **Verification:** 
- **Next step:** 
```
