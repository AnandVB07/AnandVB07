# GitHub Contribution Calendar Colors

- The calendar’s square colors encode contribution levels.
- GitHub exposes the calendar color set and an `isHalloween` indicator in its contribution calendar data.
- The orange and yellow squares in the October 31 screenshot, together with “Happy Halloween!”, indicate GitHub’s Halloween palette.
- The **Contribution settings** menu is for profile activity and visibility options; it is not evidence that someone manually recolored the calendar.
